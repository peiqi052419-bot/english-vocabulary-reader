# 偷星者与失忆公爵 · 英语词汇阅读器

打开阅读器：**[进入阅读](https://peiqi052419-bot.github.io/english-vocabulary-reader/)**

电脑、手机和平板均可通过网页阅读。首次打开需要下载约 28 MB，加载时有中文提示；如遇网络问题，可点击“重新加载”。

## 使用

1. 左上角 **☰** 选择章节。
2. 点击正文词汇，先回忆，再揭晓词义，选择“忘了／有点熟／能回忆”。
3. 每次阅读前，到 **☰ → 回顾** 复习到期词。
4. 顶部可以调整字号，切换日夜模式，开关词义、回忆与阅读练习。

## 跨设备迁移

**学习记录保存在当前设备的当前浏览器，不会自动同步。**

在 **☰ → 学习记录与设备迁移** 中，先“导出学习记录”，将下载的 JSON 备份传到另一设备，再打开同一阅读器“导入学习记录”。

- 默认合并生词和自测：同词保留较新的自评，同题保留较早的首次作答。
- 如需迁移读到的位置或显示设置，请在选择备份前勾选对应选项。
- 从原离线 HTML 转到网页，也需先在原电脑、原浏览器打开更新后的离线文件导出旧记录。
- 清理浏览器数据、隐私模式、换设备或换浏览器都可能影响本地记录，请定期导出备份。

网页不需要登录，也不会把学习记录上传到仓库。

## 部署文件

- `index.html`：阅读器界面。
- `assets/`：完整小说与词库的数据分段，需连同目录一起保留。
- `.nojekyll`：静态发布标记。

GitHub Pages 发布主分支根目录。首次阅读需联网加载全书；学习记录只保存在当前浏览器，可通过菜单导出、导入。

公开版本保留完整正文、英文词与中文释义，隐藏原始词表和 PDF 的来源文件名、页码。
